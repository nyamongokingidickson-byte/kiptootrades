# Restore notes — how this repository was populated

This repository (`nyamongokingidickson-byte/kiptootrades`) was empty except for a one-line
`README.md`. The live site at **https://www.dylantrades.site** (Vercel project `kiptootrades`)
was deployed with the Vercel CLI from a local machine, so no source code ever reached GitHub.

This repo was rebuilt on 2026-11-09 from two sources:

1. **Full application source** — `nyamongokingidickson-byte/dylantrades` (commit `092ec59`,
   "Rebrand app content as Dylan Trades"). This is the complete React + rsbuild Deriv DBot
   platform that the live deployment is built from: `src/`, `public/`, `package.json`,
   `package-lock.json`, `rsbuild.config.ts`, Jest config, lint config, docs.
2. **Files pulled verbatim from the live deployment** — the pieces that were newer than the
   GitHub source:
   - `public/service-worker.js` — the minimal passthrough worker actually served live.
   - `public/manifest.json` — the live PWA manifest (`DylanTrades`, `#414652` theme,
     Deriv 512 px icon). The matching icon was added at
     `public/assets/platform_logos/ic_platform_deriv_512x512.png`.
   - `index.html` — page title aligned with the live site
     ("Dylantrades - Your Ultimate Companion in Deriv Automations").

## What could NOT be recovered

- The compiled Vite/rsbuild bundles the live site serves (`static/js/*`, `static/css/*`,
  `static/image/*`, `static/js/async/*-xml.js`) are build **output**, not source. They are
  regenerated by `npm run build` and are deliberately not committed.
- Binary assets that exist only in the live deployment and not in the GitHub source
  (some `.mp3`, `.mp4`, `.jpg`, `.png` files under `/src/assets/`, `/src/media/`,
  `/src/videos/`) could not be downloaded — the sandbox has no outbound access to the site.
  If any of those are missing locally, re-copy them from the original working folder.

## Differences you may notice vs. the live site

The live deployment is a few commits ahead of `dylantrades@092ec59`:

- live `index.html` includes a `/callback` route rewrite for Deriv OAuth (see `vercel.json`),
- live `public/sw.js` handling was replaced by `public/service-worker.js` (PWA 404 fix),
- a few static assets were restored after being deleted.

`src/utils/pwa-utils.ts` still registers `/sw.js`. If you prefer the live behaviour, change
that registration to `/service-worker.js` — both files are present.

## Build & run

```bash
npm install
npm run build          # rsbuild build -> dist/
npm start              # rsbuild dev server
```

`vercel.json` builds with `npm run build`, serves `dist`, and rewrites all paths to
`/index.html`. `CNAME` is `dylantrades.site`.
